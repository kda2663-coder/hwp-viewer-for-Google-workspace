한글 열기 도우미 (Node.js 필요)

[이게 뭔가요]
웹 뷰어에서 "한글로 편집" 버튼을 누르면, 드라이브의 그 문서를 PC에 설치된
한글 프로그램으로 바로 열어줍니다. (다운로드 없이 드라이브 원본을 편집)

[준비물] — 보통 이미 다 있습니다
- Node.js
- Google Drive for desktop (드라이브 문자 G:/H: 무엇이든 자동 인식)
- 한글(HWP) 프로그램

[설치 — 딱 한 번만]
1. "설치.bat" 더블클릭
2. "설치 완료!" 문구가 보이면 끝
   → 이제부터 컴퓨터를 켜면 도우미가 자동으로(검은 창 없이) 켜집니다.
   → 웹 뷰어에서 "한글로 편집" 버튼만 누르면 됩니다.

[설치하기 싫으면 — 그때그때 켜기]
- "한글열기도우미_실행.bat" 더블클릭 (검은 창이 떠 있는 동안만 동작)

[제거]
- "제거.bat" 더블클릭 (자동 실행 등록만 해제)

[안 될 때]
- 처음 .bat 실행 시 "Windows의 PC 보호" 경고가 뜨면 "추가 정보 → 실행"
- 공유받은 개별 파일 / 구글폼 응답 파일은 PC 로컬에 없어서 편집이 안 됩니다(뷰어로만 보임).
- 드라이브 최상위 폴더 이름이 "내 드라이브/My Drive/공유 드라이브/Shared drives"가
  아니면 server.js의 ROOT_MARKERS 줄에 그 이름을 추가하세요.
