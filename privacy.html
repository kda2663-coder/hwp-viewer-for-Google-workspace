개인정보처리방침

HWP Editor for Google Workspace (이하 "본 서비스") · 시행일: 2026-05-29

본 서비스는 구글 드라이브에 있는 한글 문서(HWP/HWPX)를 브라우저에서 열고 편집할 수 있게 하는 도구입니다. 본 방침은 본 서비스가 어떤 정보를 다루는지 설명합니다.

1. 수집·이용하는 정보

  • 구글 계정 인증 정보: 드라이브 파일에 접근하기 위해 구글 OAuth 2.0 인증 토큰을 사용합니다. 토큰은 사용자의 브라우저 세션 내에서만 사용되며, 본 서비스 서버에 저장하지 않습니다.
  • 문서 내용: 사용자가 직접 선택해 연 한글 문서의 내용을 편집 목적으로 처리합니다.

2. 처리 방식

  • 문서 내용은 사용자의 브라우저 안에서 처리됩니다(WebAssembly 기반). 본 서비스는 문서 내용을 별도 서버로 전송하거나 저장하지 않습니다.
  • 편집 결과는 사용자의 구글 드라이브 원본 파일에 직접 저장됩니다.

3. 접근 권한 범위

본 서비스는 drive.file 권한만 사용합니다. 이는 사용자가 본 서비스로 직접 열거나 만든 파일에만 접근하는 최소 권한이며, 드라이브의 다른 파일에는 접근하지 않습니다.

4. 제3자 제공

본 서비스는 사용자의 개인정보나 문서 내용을 제3자에게 제공하지 않습니다. 파일 입출력은 구글 드라이브 API를 통해 사용자 본인의 드라이브와만 이루어집니다.

5. Google API 서비스 사용자 데이터 정책 준수

본 서비스가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책 (제한적 사용(Limited Use) 요건 포함)을 준수합니다.

6. 보관 및 파기

본 서비스는 사용자의 문서나 개인정보를 자체 서버에 보관하지 않습니다. 인증 토큰은 브라우저를 닫으면 사라집니다.
